# Полное руководство по обучению ИИ-моделей для генерации карт osu!mania 4K

Данный документ представляет собой пошаговую инструкцию полного цикла: от загрузки большого объема сырых `.osz` архивов карт до предобработки, токенизации, запуска бенчмарка производительности (CPU vs GPU) и тренировки выбранной нейросетевой модели с сохранением чекпоинтов.

---

## 1. Архитектура системы (4 ИИ-модели)

В соответствии с техническим заданием (ТЗ), пайплайн авто-маппинга состоит из 4 специализированных ИИ-компонентов:

| № | Модель / ИИ | Входные данные | Выходные данные | Роль в системе |
|---|---|---|---|---|
| **1** | **SyncBPMOffsetModel** (Синхронизация) | 80-полосная мел-спектрограмма аудио | `BPM` (темп) и `Offset` (мс до первого удара) | Точное определение темпа и начальной точки отсчета тактов |
| **2** | **DynamicsSVModel** (Динамика & SV) | Мел-спектрограмма + профиль энергии | Непрерывная кривая `Slider Velocity` и триггеры тайминг-зон | Расстановка зеленых линий тайминга (ускорения на дропах, замедления на спокойных участках) |
| **3** | **ManiaPatternTransformer** (Ядро генерации нот) | Мел-спектрограмма, вектор сложности `Star Rating` (1.0–9.9), авторегрессионный контекст | 16 классов 4K-аккордов + длительности Long Note (LN) | Основной генератор нот и паттернов (стримы, джакки, корды, холды) |
| **4** | **DifficultyEvaluatorModel** (Валидатор сложности) | Последовательность нот и плотность паттерна | Расчетный `Star Rating` (SR) | Контроль качества и проверка строгого соблюдения целевой сложности в пределах $\pm 0.3$★ |

## 2. Системные требования и подготовка окружения

### 2.1. Необходимое ПО
- **Python 3.10+** (рекомендуется Python 3.11 или 3.12)
- **PyTorch 2.0+** (`pip install torch torchvision torchaudio`)
- **ffmpeg** (обязателен для распаковки и перекодирования MP3/OGG аудио в стандартизированный 16 кГц WAV)

#### Установка FFmpeg на Windows:
Скрипт автоматически ищет `ffmpeg.exe` в следующих местах:
1. **Папка проекта** `ffmpeg/ffmpeg.exe` или `ffmpeg/bin/ffmpeg.exe` (самый простой способ!).
2. **Аргумент командной строки**: `python prepare_dataset.py --ffmpeg "C:\path\to\ffmpeg.exe"`
3. **Системный PATH Windows**: если `ffmpeg` добавлен в переменные среды.

> 💡 **Быстрая установка FFmpeg на Windows за 1 минуту:**
> 1. Скачайте архив сборки FFmpeg (например, `ffmpeg-release-essentials.zip` с официального сайта [ffmpeg.org/download.html](https://ffmpeg.org/download.html) или [gyan.dev](https://www.gyan.dev/ffmpeg/builds/)).
> 2. Откройте скачанный zip-архив, зайдите в папку `bin` и скопируйте файл `ffmpeg.exe`.
> 3. Вставьте его прямо в папку `ffmpeg/` в проекте: `AIManiaMapper4k\ffmpeg\ffmpeg.exe`.
> 4. Готово! Скрипты автоматически подхватят его.

### 2.2. Проверка окружения
Для проверки готовности системы запустите в терминале:

```bash
# 1. Проверка доступности ffmpeg
ffmpeg -version

# 2. Проверка PyTorch и наличия GPU (NVIDIA CUDA или Apple Silicon MPS)
python3 -c "
import torch
print('PyTorch Version:', torch.__version__)
print('CUDA GPU доступен:', torch.cuda.is_available())
if torch.cuda.is_available():
    print('Имя видеокарты:', torch.cuda.get_device_name(0))
"
```

Если у вас видеокарта NVIDIA, убедитесь, что установлен PyTorch с поддержкой CUDA:
```bash
# Пример установки PyTorch с CUDA 12.1 (для внешних машин / серверов)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

## 3. Шаг 1: Добавление карт в датасет

Сложите все ваши `.osz` файлы (десятки, сотни или тысячи карт) в папку `sample beatmaps/` (или любую другую удобную директорию, например `my_songs/`).

### Требования к картам:
- Формат архивов: стандартные `.osz` файлы osu!.
- Карты должны содержать режим **osu!mania 4K** (`Mode: 3`, `CircleSize: 4`). 
- Экстрактор автоматически отфильтрует карты других режимов (Standard, Taiko, Catch, 7K) и извлечет только 4K-сложности.

---

## 4. Шаг 2: Разбор карт на составные элементы (Препроцессинг & Токенизация)

Перед тренировкой нейросетей сырые аудиозаписи и текстовые `.osu` файлы необходимо превратить в тензоры PyTorch:
1. **Декодирование звука**: извлечение главного аудио-трека песни и конвертация через ffmpeg в 16 000 Гц моно `.wav`.
2. **Мел-спектрограмма**: расчет 80-полосной логарифмической мел-спектрограммы с шагом фрейма 16 мс (hop_length=256).
3. **16-классовая токенизация нот**: 
   Для 4 клавиш mania существует ровно $2^4 = 16$ дискретных состояний аккордов:
   - `0`: пустой фрейм (тишина / пауза)
   - `1`: клавиша 1 (`[1, 0, 0, 0]`)
   - `2`: клавиша 2 (`[0, 1, 0, 0]`)
   - `3`: двойной аккорд (`[1, 1, 0, 0]`)
   - ...
   - `15`: квадро-корд (`[1, 1, 1, 1]`)
4. **Маски Long Notes (LN)**: фиксация удержания лонг-нот по каждой из 4 колонок.
5. **Нарезка на чанки**: разбиение длинных композиций на обучающие сегменты длиной 256 фреймов (~4.1 сек) с шагом перекрытия 128 фреймов (~2.0 сек).

### Запуск препроцессинга в один клик:

**Для Windows PowerShell:**
```powershell
.\prepare_dataset.ps1
```
*(Или в командной строке CMD: `prepare_dataset.bat`)*

**Для Linux / macOS / Git Bash:**
```bash
./prepare_dataset.sh
```

Либо напрямую через Python с настройкой параметров:
```bash
python prepare_dataset.py \
    --input_dir "sample beatmaps" \
    --output_dir "dataset_processed" \
    --chunk_size 256 \
    --hop_size 128
```
*(Если `ffmpeg.exe` лежит в нестандартном месте, добавьте `--ffmpeg "C:\путь\к\ffmpeg.exe"`)*

### Результат выполнения:
- Создается файл **`dataset_processed/train_data.pt`** — готовый скомпилированный бинарный датасет со всеми обучающими тензорами.
- Создается манифест **`dataset_processed/metadata.json`** с полной статистикой по всем извлеченным сложностям, BPM, Star Rating и количеству сэмплов.

## 5. Шаг 3: Бенчмаркинг скорости (CPU vs GPU)

Перед длительной тренировкой рекомендуется запустить бенчмарк, который измерит задержку шага (latency), пропускную способность (samples/second) и рассчитает точное время обучения выбранной модели на CPU и GPU.

### Запуск бенчмарка:
```bash
./benchmark.sh [номер_модели] [размер_батча] [число_шагов]
```

Например, для тестирования Трансформера (Модель 3):
```bash
./benchmark.sh 3 16 20
```
Или через Python:
```bash
python3 benchmark_train.py --model 3 --batch_size 16 --steps 20
```

## 6. Шаг 4: Запуск тренировки выбранного ИИ

Обучение запускается с помощью скрипта `train.sh` или команды `python3 train.py`.

### 6.1. Быстрый запуск через bash-скрипт:
Синтаксис:
```bash
./train.sh [номер_модели] [устройство] [эпохи] [размер_батча] [learning_rate]
```

#### Примеры:
- **Тренировка Модели 3 (ManiaPatternTransformer) на GPU на 20 эпох:**
  ```bash
  ./train.sh 3 gpu 20 16
  ```

- **Тренировка Модели 1 (Sync BPM/Offset) на CPU на 10 эпох:**
  ```bash
  ./train.sh 1 cpu 10 32
  ```

- **Тренировка Модели 2 (Dynamics SV) на GPU:**
  ```bash
  ./train.sh 2 gpu 15 32
  ```

- **Тренировка Модели 4 (Evaluator сложности) на GPU:**
  ```bash
  ./train.sh 4 gpu 12 32
  ```

- **Последовательная тренировка ВСЕХ 4 моделей подряд:**
  ```bash
  ./train.sh all auto 15 16
  ```

---

### 6.2. Детальный запуск через `train.py`

Для тонкой настройки параметров используйте аргументы командной строки:

```bash
python3 train.py \
    --model 3 \
    --device cuda \
    --dataset dataset_processed/train_data.pt \
    --checkpoint_dir checkpoints \
    --epochs 25 \
    --batch_size 16 \
    --lr 0.0002 \
    --val_split 0.1
```

#### Параметры:
- `--model` (`-m`): `1` (sync), `2` (dynamics), `3` (transformer), `4` (evaluator), или `all`.
- `--device` (`-d`): 
  - `cuda` (NVIDIA GPU с тензорными ядрами)
  - `mps` (Apple Silicon M1/M2/M3/M4 GPU)
  - `cpu` (многопоточный процессор)
  - `auto` (автоматический выбор лучшего доступного ускорителя)
- `--batch_size` (`-b`): размер пачки сэмплов (для CPU рекомендуется 8–16, для GPU 16–64).
- `--epochs` (`-e`): количество полных проходов по датасету.
- `--lr`: скорость обучения (learning rate), по умолчанию `0.0002`.

## 7. Чекпоинты и результаты обучения

Во время обучения скрипт непрерывно валидирует качество на отложенной выборке (`val_split`). При каждом улучшении метрик лучшая версия модели автоматически сохраняется в папку `checkpoints/`:

- `checkpoints/model_1_sync_best.pt` — веса модели синхронизации темпа
- `checkpoints/model_2_dynamics_best.pt` — веса модели динамики и SV
- `checkpoints/model_3_transformer_best.pt` — веса генератора паттернов
- `checkpoints/model_4_evaluator_best.pt` — веса валидатора сложности

### Метрики, отслеживаемые в процессе:
- **Модель 3 (Трансформер)**: 
  - `Train Loss` / `Val Loss` — совместная функция потерь (CrossEntropy аккордов + BCE лонг-нот).
  - `Acc` (%) — процент точно угаданных 4K-конфигураций клавиш во временной сетке.
- **Модель 1 (Sync)**:
  - `BPM MAE` — средняя абсолютная погрешность определения темпа в ударах в минуту (целевое значение: < 1.0 BPM).
- **Модель 2 (Dynamics)**:
  - `SV MSE` — среднеквадратичная ошибка соответствия карты скоростей прокрутки.
- **Модель 4 (Evaluator)**:
  - `SR MAE` — точность попадания в целевой Star Rating (целевое значение: < 0.25★).

## 8. Использование обученной модели для генерации карт

После завершения обучения сохраненный чекпоинт `checkpoints/model_3_transformer_best.pt` готов к генерации новых карт из любого аудиофайла:

```bash
# Генерация карты 4.5★ из нового трека song.mp3
python3 -m osu_mapper.pipeline \
    --audio "my_new_track.mp3" \
    --title "My Generated Beatmap" \
    --artist "Cool Artist" \
    --diff "4.5" \
    --checkpoint "checkpoints/model_3_transformer_best.pt" \
    --output "output_maps/generated_map.osz"
```

Готовый файл `.osz` можно сразу открыть двойным кликом в клиенте osu! и играть.

## 9. Частые вопросы и решение проблем (FAQ & Troubleshooting)

### В: Ошибка `[WinError 2] Не удается найти указанный файл` при обработке архивов
**О:** Данная ошибка в Windows возникает, когда скрипт пытается вызвать внешнюю утилиту `ffmpeg`, но исполняемый файл `ffmpeg.exe` не найден.
**Решение:**
1. Скачайте `ffmpeg.exe` (например, zip-архив с [ffmpeg.org](https://ffmpeg.org/download.html)).
2. Скопируйте файл `ffmpeg.exe` прямо в папку `ffmpeg/` в корне проекта (`AIManiaMapper4k\ffmpeg\ffmpeg.exe`). Скрипт автоматически найдет его там.
3. Либо укажите путь через флаг:
   ```powershell
   python prepare_dataset.py --ffmpeg "C:\Users\...\ffmpeg.exe"
   ```

### В: Как запускать скрипты в Windows PowerShell?
**О:** Для всех операций созданы нативные `.ps1` (PowerShell) и `.bat` скрипты:
- Препроцессинг: `.\prepare_dataset.ps1` (или `prepare_dataset.bat`)
- Бенчмарк: `.\benchmark.ps1 -Model 3` (или `benchmark.bat 3`)
- Обучение: `.\train.ps1 -Model 3 -Device cuda -Epochs 20` (или `train.bat 3 cuda 20`)

### В: Что делать при ошибке `CUDA out of memory` (OOM)?
**О:** Память видеокарты переполнена. Уменьшите размер батча:
```bash
./train.sh 3 gpu 20 8    # уменьшите batch_size с 16 до 8 или 4
```

### В: Можно ли прервать обучение комбинацией Ctrl+C?
**О:** Да. Лучший чекпоинт (`*_best.pt`) сохраняется сразу же после каждой успешной эпохи, поэтому достигнутый прогресс не потеряется.

### В: Как дообучить модель на новых картах?
**О:** 
1. Положите новые `.osz` файлы в `sample beatmaps/`.
2. Запустите `.\prepare_dataset.ps1` (или `./prepare_dataset.sh`), чтобы обновить `train_data.pt`.
3. Запустите `.\train.ps1 -Model 3 -Device cuda -Epochs 15` (или `./train.sh 3 gpu 15 16`).
